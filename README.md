# 🎓 Academic Portfolio Website

A modern, interactive, and fully responsive **academic portfolio website** built using **HTML, CSS, and JavaScript**.  
This portfolio showcases academic background, technical skills, projects, certifications, publications, and achievements with a strong focus on **UI/UX, animations, and interactive components**.

## ✨ Key Features

### 🧭 Navigation & Layout
- Fixed **glassmorphism-style navbar** with smooth scrolling
- Section-based layout (About, Skills, Projects, Certificates, Publications, etc.)
- Fully responsive design for desktop, tablet, and mobile
- Clean grid-based layout system across all sections

---

### 🌙 Dark Mode Support
- Light / Dark theme toggle
- Theme preference stored using **LocalStorage**
- CSS variables for seamless theme switching across the site

---

### 👤 Hero & Profile Section
- Profile card with avatar, role, organization, and social links
- Responsive two-column hero layout
- Emphasis on academic and cybersecurity profile

---

### 🧠 Skills Section (Advanced)
- **Category-based filtering** (Programming, Cybersecurity, Tools)
- Animated **skill progress bars**
- Skill cards with:
  - Hover animations
  - Double-click interaction
  - Modal popups showing detailed skill info
- Visual indicators for proficiency percentages

---

### 📁 Projects Section
- Project cards with:
  - Hover zoom animation on images
  - Tags for tech stack
  - Live demo & source code buttons
- **Project filtering system** (Cybersecurity / Web / Python)
- Smooth fade-in animation on filter change

---

### 📜 Certifications Section
- Certificate cards with:
  - Image preview
  - Issuer badge
  - Hover-based **overlay reveal**
- Overlay includes:
  - Certificate details
  - Skills gained
  - Direct certificate link
- “View All Certificates” CTA

---

### 🏆 Achievements Section
- Interactive achievement list
- Click-to-open modal for additional details
- Clean timeline-style presentation

---

### 📚 Publications Section
- Publication card with:
  - Book cover preview
  - Detailed description
  - Metadata (Publisher, DOI, ISBN)
  - External link to published work
- Responsive layout for mobile and desktop

---

### 🎓 Education Timeline
- Structured academic history cards
- Hover animations and emphasis on degree details
- External links to institutions

---

### 📬 Contact & Communication
- Integrated contact form (Formspree-ready)
- Direct email CTA card
- Social media grid with hover effects
- Fully responsive contact layout

---

### 🪟 Modal System
- Reusable modal component
- Used across:
  - Skills
  - Achievements
  - Bug/Mistake reports
- Smooth open/close animations
- Click-outside-to-close support

---

### 🐞 Floating Bug / Mistake Report System
- Floating action button (FAB)
- Expandable report options:
  - Report Bug
  - Report Mistake
- Animated reveal & hide behavior
- Designed for future backend integration

---

## 🎨 UI / UX Highlights

- Modern academic & professional design
- Smooth hover, scale, and fade animations
- Card-based layout for clarity
- Clear visual hierarchy
- Accessibility-friendly font sizes and spacing

  - CSS Variables

  - DOM manipulation

  - Modal & filter logic
